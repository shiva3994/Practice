# 7-Day Practice Plan — Excel + Python + SQL + Power BI
### Using your Airbnb Antwerp dataset (5 tables) — 40 Qs/day (10 each), Day 1→7 goes Easy → Intermediate → Moderate → Hard

**Tables you have:**
- `Listings` — listing_id, name, property_type, room_type, accomodates, bathrooms_text, bedrooms, beds, amenities, latitude, longitude, host_id
- `Hosts` — host_id, host_name, host_since, host_location, HostAgeYears, HasBio, BioLength
- `Calendar` — listing_id, date, available, price, adjusted_price, minimum_nights, maximum_nights
- `Reviews` — review_id, listing_id, date, reviewer_id, reviewer_name, comments, ReviewLength
- `Amenities` — listing_id, amenity (long format — one row per amenity per listing)

**Difficulty map:** Day 1–2 = Easy | Day 3–4 = Intermediate | Day 5–6 = Moderate | Day 7 = Hard
**Python rule:** every day includes 1 visual (chart) built from that day's questions, and Day 1–2 lean extra hard on basics (syntax, pandas fundamentals) before Day 3 speeds up.

## How to use this
- Do the 4 tools back-to-back each day, or split across morning/evening — order doesn't matter, just hit all 40.
- Don't look up "the answer" first — attempt, get stuck, *then* check docs/ask. That's where retention happens.
- Keep a single running notes file (or one Excel tab) logging: what tripped you up each day → review those on Day 7 morning before the capstone.
- If a question needs a column that doesn't exist yet (e.g., price band, tenure), that's intentional — building it *is* the exercise.
