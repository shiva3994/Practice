# 7-Day SQL + Python Practice Plan (Big4 India Dataset)

**Format:** Each day has 20 SQL + 20 Python questions, grouped into 4 concept "types" of 5 questions each. Every group drills one skill through repetition — same pattern, different table/column/condition — so you build muscle memory before moving to the next concept.

**Tables & columns (for reference):**
- `Clients` — Client_ID, Company, Industry, Country, ContractValue
- `Company_Financials` — Financial_ID, Company, Year, Quarter, Revenue, Profit, Employees
- `Employees` — Employee_ID, Company, Department, Role, Age, Salary, JoinDate
- `Office_Locations` — Office_ID, Company, Country, State, City, Employees
- `Projects` — Project_ID, Company, Client_ID, Employee_ID, Technology, Budget, Status
- `Technologies` — Technology_ID, Company, Technology, Project_ID, Popularity

In pandas, assume each CSV is loaded as a lowercase-suffixed DataFrame: `clients`, `financials`, `employees`, `offices`, `projects`, `technologies`.
